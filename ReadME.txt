# 🎬 Movie Fan Club & Music Player Webpage

An interactive, responsive, and visually stunning fan club webpage dedicated to blockbuster movies like **Hridayam** and **Sita Ramam**. This project features a curated cast showcase with interactive elements, a fully custom music streaming grid, video integrations for trailers/behind-the-scenes, and a user feedback form with a dynamic star rating system.

## 🚀 Features

- **📱 Responsive Navigation:** A clean, fixed top navbar enabling smooth navigation across different sections of the website.
- **🖼️ Poster Showcase (Home):** A beautifully aligned landing container designed to feature high-quality movie posters.
- **👥 Cast & Crew Gallery:** A stylized biographical showcase featuring lead actors (Pranav Mohanlal, Kalyani Priyadarshan, Darshana Rajendran) with custom gradient CTA action buttons.
- **🎵 Multi-Song 4x2 Grid Player:** A sleek, organized grid displaying 8 hit movie tracks in an exact 4-columns per row format.
- **🔇 Smart Audio Control (Single Play):** Powered by custom JavaScript, playing any song will automatically pause any other playing audio track instantly—matching professional streaming platforms.
- **⬇️ Direct Download Links:** Native browser download compatibility baked right into every song card.
- **🎥 Multimedia Integration:** embedded dedicated video panels to play Movie Trailers and Behind the Scenes (BTS) footage seamlessly.
- **⭐ Interactive Fan Club Form:** A functional feedback layout with an input registry, message textarea, and a styled CSS-only reverse star rating component.

## 🛠️ Tech Stack Used

- **HTML5:** Semantic architecture (`<header>`, `<main>`, `<section>`, `<video>`, `<audio>`) ensuring standard SEO compliance.
- **CSS3:** Advanced layouts leveraging Flexbox and CSS Grid alongside linear-gradient color schemas, pseudo-selectors (`:hover`), and custom component styling.
- **JavaScript (Vanilla):** Dynamic DOM manipulation for the smart single-audio playback logic.

## ⚙️ How to Setup and Run

1. Clone or download this repository to your local machine.
2. Ensure your media assets are structured correctly inside a `./media/` directory relative to your main code files.
3. Open `index.html` directly in any modern web browser (Google Chrome, Microsoft Edge, Safari, Mozilla Firefox).
4. For testing style changes locally, clear your browser cache using `Ctrl + F5` (Hard Refresh) to instantly sync your latest updates.
